# EOS 资源包造日志脚本

脚本：`gen_eos_resource_log.py`

## 口径（以费用中心订单为准）

订单示例（下行流量包）：

| 字段 | 值 |
|------|-----|
| 订单编号 | `MOP-T-26010448398352` |
| 订单批次编号 | `MOP-O-26010441749060` |
| 订购账号 | `yunchenkeji` |
| 商品名称 | 对象存储包 |
| 配置 | 对象存储下行流量包(GB): **51200** |
| 资源ID | `18733c89fdcf499eb252e0dfffd6f931` |
| 订购关系ID | `10062663572` |
| 开通时间 | **2026-01-04 17:13:04** |
| 到期时间 | **2026-04-04 17:13:04** |
| 计费方式 | 包月计费 |
| 单价/总金额 | 19497 元/月，合计 ¥58491.00（3 个月） |

- 项目期共 **3 个月**
- 资源数是 **每月额度**
- **每月 4 号**新计费周期，使用量从 **0** 重置并缓慢增长到约 60%~80%

### 每月额度

| 类型 | 单包 | 包数 | 每月总量 |
|------|------|------|----------|
| 标准存储次数包 | 10000 万次 | 6 | **6 亿次 / 月** |
| 对象存储容量包 | 512000 GB | 6 | **3 PB / 月** |
| 下行流量包 | 51200 GB | 6 | **300 TB / 月** |

### 单包时间字段

- `active=2026-01-04 17:13:04`
- `expire=2026-04-04 17:13:04`

## 用法

```bash
python3 scripts/gen_eos_resource_log.py \
  --start "2026-01-04 17:13:04" \
  --end 20260331 \
  -o /tmp/eos_resource.log
```

## 关键字段

- `ORDER`：订单编号、批次、开通/到期、资源ID、订购关系ID、单价等
- `CALL_PKG` / `CAP_PKG` / `TRAFFIC_PKG`：当月总量、已用、剩余、使用率
- `TRAFFIC_PKG#N`：含 `resource_id` / `subscribe_id` / `order_no` / `cfg=对象存储下行流量包(GB):51200`
- `USAGE_RESET`：每月 4 号换期，使用量从 0 重新累计
- `QUOTA` / `FINAL_CHECK`
