# EOS 资源包造日志脚本

脚本：`gen_eos_resource_log.py`

## 口径（已按业务澄清）

- 项目期共 **3 个月**
- 资源数是 **每月额度**（不是 3 个月累计）
- 每个资源包有效期 **仅 1 个月**，到期自动续订
- 订购时间约 **2026-01-04 17:15**
- 自动续订最终到期 **2026-04-04**

### 每月额度

| 类型 | 单包 | 包数 | 每月总量 |
|------|------|------|----------|
| 标准存储次数包 | 10000 万次 | 6 | **6 亿次 / 月** |
| 对象存储容量包 | 512000 GB | 6 | **3 PB / 月** |
| 下行流量包 | 51200 GB | 6 | **300 TB / 月** |

### 三个账期（用量按月重置；单包控制台到期日统一为 2026-04-04）

| 账期 | 月度额度周期 | 单包 active | 单包 expire |
|------|--------------|-------------|-------------|
| M1 | 2026-01-04 17:15 ~ 2026-02-04 17:15 | 2026-01-04 17:15 | **2026-04-04 17:15** |
| M2 | 2026-02-04 17:15 ~ 2026-03-04 17:15 | 2026-01-04 17:15 | **2026-04-04 17:15** |
| M3 | 2026-03-04 17:15 ~ 2026-04-04 17:15 | 2026-01-04 17:15 | **2026-04-04 17:15** |

已使用量按 **当月额度** 的 60%~80% 造数（当月内从约 60% 爬到约 80%）。

## 用法

```bash
python3 scripts/gen_eos_resource_log.py \
  --start "2026-01-04 17:15:00" \
  --end 20260331 \
  -o /tmp/eos_resource.log
```

## 关键字段

- `ORDER` / `BILLING_CYCLE` / `AUTORENEW`：订购、账期、续订
- `CALL_PKG` / `CAP_PKG` / `TRAFFIC_PKG`：当月总量、已用、剩余、使用率
- `active` / `expire`：单包生效=订购时间 `2026-01-04 17:15:00`，到期=自动续订最终到期 `2026-04-04 17:15:00`
- `QUOTA`：简要配额（含 `pkg_expire`、`final_expire`）
- `FINAL_CHECK`：结束校验（注明为当月额度）
